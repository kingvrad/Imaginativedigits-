# Simbabot

Simbabot is a demo-first automated trading platform prototype.

## Current version
- Green/black Simbabot branding
- Homepage
- Signup screen
- Login screen
- Demo dashboard
- No real credentials or trading connections
- No live trading

## Next build
1. Supabase authentication and database
2. Protected dashboard
3. Subscription/payment layer
4. Secure MT5 integration
5. Demo trading engine
6. Security and risk controls

Never put a Supabase service-role key, broker master password, or other secret into frontend code.
